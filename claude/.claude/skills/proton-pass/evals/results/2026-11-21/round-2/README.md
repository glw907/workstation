Case 4 is the only query whose behaviors are all met with the skill off, on all three models. That is expected for the out-of-scope case, whose job is to show the skill stays unloaded, so it doesn't separate on from off. No in-scope query is fully met with the skill off on any model. Every skill-off session in cases 1 to 3 had its reads of the skill and `secrets.md` denied and said so, and the behaviors it met came from the global CLAUDE.md.

No behavior was missed with the skill on.

Two judgment calls in the skill-off column: `2-sonnet-off` and `2-opus-off` count as meeting behavior 1 because each names throttling as its lead diagnosis while flagging it as unverified; `2-haiku-off` does not, because its lead cause is session expiry. No session used a write tool. Tools used across the round were `Read`, `Glob`, `Grep`, and `Skill`, and every answer says nothing was run or changed.
