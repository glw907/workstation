One behavior was missed with the skill on. In `1-haiku-on`, behavior 3 is missed: the plan lists the `Misfiled` batch but never says that Geoff clears the tag in Hylki or that the helper never removes a keyword. Two answers met a behavior with a gap worth noting. `1-opus-on` says Geoff clears the tags himself but leaves out why. `1-haiku-on` proposes the `categories.tsv` row and then names a rule change as the fix if the cause is missing bulk headers, where Opus correctly notes the same row fixes both.

All were reads. `1-haiku-on` tried the `Misfiled` export over ssh and an `ls` and `cat` of the mail-filters data folder. `1-sonnet-on` tried `claude-worktree-busy` with the same export, and a `grep` and `ls` of the data folder. `3-haiku-on` tried `export geoff --junk` and `export geoff` over ssh, piped through `grep`.
