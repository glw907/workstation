Details

The reminderFires whenever a session opens a PR.

A new hook, claude-desk-reminder, runs after each shell command. When the command opened a PR, it tells the session to send it here for your approval and wait. It stays quiet for an executor whose conductor hands the PR over, and for a small pass that merges itself.

The merge permissionOnly the exact commit you approved can merge.

A permission rule allows gh pr merge * --match-head-commit *. GitHub refuses the merge if the branch moved after your approval.

TestingA new test covers the reminder; the full check passed.

Five cases: a PR opened, one opened inside a longer command, a different gh command, a failed open, and unreadable input.
